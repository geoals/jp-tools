**Windows** — download `kotodex-<version>-windows-setup.exe` and run it. It is not
signed, so Windows says "Windows protected your PC": *More info* → *Run anyway*.

**Linux** — `tar xf kotodex-<version>-linux-x86_64.tar.gz && cd kotodex-<version> && ./setup.sh`

First start downloads about 175 MB of dictionaries. You also need
[Textractor](https://github.com/Artikash/Textractor) with its WebSocket
extension for the lines, and Anki with AnkiConnect if you want to mine cards.
